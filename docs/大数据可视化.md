《大数据可视化》课程实践作业任务书
本任务书与"2026年第十四届全国大学生数字媒体科技作品及创意竞赛"衔接，作业成果可直接转化为参赛材料
一、作业定位与目标
本作业是《大数据可视化》课程的综合实践环节。各小组借助智能体（AI Agent）独立完成一个完整的数据可视化项目，覆盖"选题—数据—设计—开发—交付"全流程，重点考察学生定义问题和驾驭智能体的能力。
本作业不考核手写代码量，重点考核以下四种能力：
●	定义真实问题、获取与规范处理数据的能力；
●	数据可视化设计与信息表达能力；
●	驾驭智能体完成项目开发的能力：需求描述、提示词设计、迭代推进、验收与修正；
●	成果表达与展示能力（文档、PPT、视频、现场演示）。
同时，本作业与2026年第十四届全国大学生数字媒体科技作品及创意竞赛（官网：www.cmit.cn）衔接：作业交付物对照比赛申报材料设计，可直接报名参赛。所有同学不管是否参赛，

三、任务要求
（一）选题的四个硬条件
题目自拟，但必须同时满足：
●	有可视化内容：以数据可视化/信息可视化为主体，形态不限（交互网页、可视化大屏、数据故事等均可）；
●	作品完整：可运行、可访问、可演示，不得仅提交效果图、概念稿或静态展示；
●	有价值：面向真实问题和真实数据，能清楚说明"给谁看、解决什么认知问题"；
●	有创新点：视角、叙事、交互或视觉表达中至少有一处体现自己的原创构思。
（二）选题引导（供参考，可自拟）
城市夜经济活力、校园能耗与碳排放、气候变化三十年、非遗与地方文化传播、电商消费结构变迁、公共交通潮汐规律、体育赛事数据洞察、所学专业相关行业数据透视等。鼓励结合专业背景与社会热点选题；题材契合乡村振兴、红色文化、民族文化等方向的，参赛时可选择相应指定命题赛道，立意上更占优势。
（三）数据与合规要求
●	数据来源限定为公开合规渠道：国家统计局、各级政府开放数据平台、世界银行、Kaggle、天池等公开数据集；
●	须在说明文档中注明数据来源、规模、字段与处理方法；
●	涉及第三方素材、字体、模型、代码的，须注明来源及授权情况；
●	不得使用涉及个人隐私或来源不明的数据。
