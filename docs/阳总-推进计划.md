## 二、推进路线（建议顺序）

### 阶段 1：建数据库表（后端基础）

没有数据表，什么都接不了。需要新建以下表：

```
 jobs          — 岗位表（企业发布、求职者浏览）
 skills        — 技能标签表
 job_skills    — 岗位-技能关联表
 match_records — 人岗匹配记录表
 skill_graph   — 技能图谱关系表（节点+边）
 trends        — 趋势数据表
```

**执行步骤**：
1. 在 `backend/database.py` 中添加上述 Model 类
2. 后端启动时 `init_db()` 会自动建表
3. 手动导入一批种子数据（至少 20 条岗位 + 技能标签）用于测试

**产出**：数据库就绪，有可用的测试数据

---

### 阶段 2：补后端 API

按优先级排序（先做你负责的模块需要的接口）：

| 优先级 | 接口 | 说明 | 对应前端页面 |
|:------:|------|------|-------------|
| P0 | `GET /api/jobs` | 岗位列表（支持搜索/筛选） | 匹配、趋势 |
| P0 | `GET /api/jobs/:id` | 岗位详情 | 匹配 |
| P0 | `POST /api/match` | 人岗匹配（输入用户ID+岗位ID，返回匹配分数） | 匹配 |
| P0 | `GET /api/trends` | 趋势数据（技能需求变化、薪资趋势） | 趋势、市场洞察 |
| P1 | `GET /api/skills` | 技能标签列表 | 人才星筛选 |
| P1 | `GET /api/candidates` | 候选人搜索（企业端） | 人才星 |
| P1 | `GET /api/graph` | 技能图谱数据（节点+边） | 市场洞察 |
| P2 | `GET /api/dashboard/stats` | Dashboard 统计数据 | 各端仪表盘 |

**执行步骤**：
1. 在 `backend/` 下新建 `routers/jobs.py`、`routers/match.py`、`routers/trend.py`
2. 在 `main.py` 中注册新路由
3. 每个接口写完后用浏览器或 Postman 验证

**产出**：后端 API 可用，前端可以开始对接

### 阶段 3：前端对接（你的核心工作）

#### 3.1 求职端 / 匹配页面（`Match.tsx`）

**当前**：硬编码 `score=72`、固定技能列表、固定建议文字

**需要改成**：
- 页面加载时调用 `GET /api/jobs` 拉取岗位列表
- 用户选择岗位后，调用 `POST /api/match` 获取真实匹配结果
- 展示返回的匹配分数、维度评分、已掌握/待提升技能、改进建议
- 支持切换不同岗位重新匹配

#### 3.2 企业端 / 人才星页面（`TalentSearch.tsx`）

**当前**：硬编码 6 个候选人、假的匹配分数

**需要改成**：
- 调用 `GET /api/candidates` 拉取候选人列表
- 搜索框和岗位筛选调后端 API 做真实过滤
- 每个候选人卡片显示真实技能、经验、匹配度
- 点击可查看详情

#### 3.3 求职端 / 趋势页面（`Trend.tsx`）

**当前**：Recharts 图表用假数据渲染

**需要改成**：
- 调用 `GET /api/trends` 获取真实趋势数据
- 折线图、柱状图数据从 API 返回
- "新岗位" 和 "更新" 标签页数据也从 API 获取

#### 3.4 企业端 / 市场洞察页面（`MarketInsight.tsx`）

**当前**：假的上升/下降技能列表 + 静态图谱

**需要改成**：
- 调用 `GET /api/trends` 获取技能趋势数据
- 上升技能、下降技能、新兴岗位数据从 API 获取
- 图谱数据从 `GET /api/graph` 获取

## 五、注意事项

1. **App.tsx 有 bug**：`handleLogin` 里写死了 `demo_token`，会覆盖掉 Login.tsx 从 API 拿到的真实 token。对接时需要先修这个。
2. **Token 传递方式**：后端用 query parameter `?token=xxx` 传 token，前端 fetch 时需要带上。
3. **CORS 已放开**：后端 `allow_origins=['*']`，前端跨域没问题。
4. **没有分页**：当前接口都没有分页，数据量大了需要补。先做功能，后加分页。
