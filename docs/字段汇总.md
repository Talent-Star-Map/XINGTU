## 整合

|      字段名      |       类型       |                   说明                    |
| :--------------: | :--------------: | :---------------------------------------: |
|        id        |      BIGINT      |                 全局主键                  |
|    data_type     | TINYINT NOT NULL |  数据类型：1=岗位(Job)，2=文章(Article)   |
|      source      |   VARCHAR(50)    |       数据来源（智联招聘、CSDN 等）       |
|    source_url    |   VARCHAR(500)   |               原始数据链接                |
|      title       |   VARCHAR(300)   | 标题（岗位=job_name，文章=article_title） |
|    skill_tags    |       JSON       |                 技能标签                  |
| technology_field |   VARCHAR(100)   |    技术领域（岗位分类或文章技术领域）     |
|   company_name   |   VARCHAR(200)   |          公司名称（文章为NULL）           |
|       city       |   VARCHAR(100)   |                 工作城市                  |
|       area       |   VARCHAR(100)   |                 工作地区                  |
|    salary_min    |       INT        |              最低月薪（元）               |
|    salary_max    |       INT        |              最高月薪（元）               |
|  salary_months   |       INT        |               薪资发放月数                |
|    education     |   VARCHAR(50)    |                 学历要求                  |
|    experience    |   VARCHAR(50)    |               工作经验要求                |
|     job_type     |   VARCHAR(50)    |          工作类型（全职/实习等）          |
|   company_type   |   VARCHAR(100)   |                 企业性质                  |
| job_description  |     LONGTEXT     |                 岗位描述                  |
|      author      |   VARCHAR(100)   |                   作者                    |
|     summary      |       TEXT       |                 文章摘要                  |
|   article_type   |   VARCHAR(50)    |                 文章类型                  |
|  quality_score   |   DECIMAL(5,2)   |               内容质量评分                |
|    hot_score     |   DECIMAL(8,2)   |               综合热度评分                |
|   trend_score    |   DECIMAL(8,2)   |                 趋势评分                  |
|    view_count    |       INT        |                  阅读量                   |
|    like_count    |       INT        |                  点赞量                   |
|  collect_count   |       INT        |                  收藏量                   |
|  comment_count   |       INT        |                  评论量                   |
|   publish_time   |     DATETIME     |               信息发布时间                |
|    crawl_time    |     DATETIME     |               数据采集时间                |
|   update_time    |     DATETIME     |               数据更新时间                |
