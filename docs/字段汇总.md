## user_skills — 用户已掌握技能

| 字段名 | 类型 | 说明 |
|--------|------|------|
| id | INT AUTO_INCREMENT | 主键 |
| user_id | INT NOT NULL | 用户ID，关联 jobseekers.id |
| job_id | INT DEFAULT NULL | 关联岗位ID，NULL表示通用技能 |
| skill_name | VARCHAR(100) NOT NULL | 技能名称 |
| mastered | TINYINT(1) DEFAULT 0 | 是否已掌握：0=未掌握，1=已掌握 |
| mastered_at | DATETIME DEFAULT NULL | 标记掌握的时间 |
| created_at | DATETIME DEFAULT CURRENT_TIMESTAMP | 创建时间 |
| updated_at | DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP | 更新时间 |

索引：`idx_user_job (user_id, job_id)`、`idx_user_skill (user_id, skill_name)`


## diagnosis_history — 诊断历史记录

| 字段名 | 类型 | 说明 |
|--------|------|------|
| id | INT AUTO_INCREMENT | 主键 |
| user_id | INT NOT NULL | 用户ID，关联 jobseekers.id |
| job_id | INT NOT NULL | 岗位ID |
| job_title | VARCHAR(200) DEFAULT '' | 岗位标题 |
| job_company | VARCHAR(200) DEFAULT '' | 公司名称 |
| job_location | VARCHAR(100) DEFAULT '' | 工作地点 |
| job_salary | VARCHAR(50) DEFAULT '' | 薪资范围 |
| overall | DECIMAL(5,1) DEFAULT 0 | 综合匹配分数 |
| grade | VARCHAR(5) DEFAULT '' | 等级：S/A/B/C/D |
| have_count | INT DEFAULT 0 | 已掌握技能数 |
| miss_count | INT DEFAULT 0 | 缺失技能数 |
| skills | JSON | 完整技能数据：{have, miss, extra} |
| phases | JSON | 学习阶段数据 |
| recommendations | JSON | 改进建议列表 |
| created_at | DATETIME DEFAULT CURRENT_TIMESTAMP | 创建时间 |

索引：`idx_user (user_id)`、`idx_job (job_id)`、`idx_created (created_at)`


## learning_progress — 学习进度

| 字段名 | 类型 | 说明 |
|--------|------|------|
| id | INT AUTO_INCREMENT | 主键 |
| user_id | INT NOT NULL | 用户ID，关联 jobseekers.id |
| job_id | INT NOT NULL | 岗位ID |
| skill_name | VARCHAR(100) NOT NULL | 技能名称 |
| status | VARCHAR(20) DEFAULT 'pending' | 学习状态：pending/learning/mastered |
| started_at | DATETIME DEFAULT NULL | 开始学习时间 |
| mastered_at | DATETIME DEFAULT NULL | 掌握时间 |
| study_minutes | INT DEFAULT 0 | 学习时长（分钟） |
| created_at | DATETIME DEFAULT CURRENT_TIMESTAMP | 创建时间 |
| updated_at | DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP | 更新时间 |

唯一约束：`uk_user_job_skill (user_id, job_id, skill_name)`
索引：`idx_user_job (user_id, job_id)`


## skill_resources — 技能学习资源

| 字段名 | 类型 | 说明 |
|--------|------|------|
| id | INT AUTO_INCREMENT | 主键 |
| skill_name | VARCHAR(100) NOT NULL | 技能名称，如 Python |
| resource_type | VARCHAR(20) DEFAULT '文档' | 资源类型：文档/教程/视频/课程/搜索 |
| title | VARCHAR(300) NOT NULL | 资源标题 |
| url | VARCHAR(500) NOT NULL | 资源链接 |
| sort_order | INT DEFAULT 0 | 排序权重（越小越靠前） |
| created_at | DATETIME DEFAULT CURRENT_TIMESTAMP | 创建时间 |
| updated_at | DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP | 更新时间 |

索引：`idx_skill_name (skill_name)`

数据：33 个技能、88 条资源，通过 `backend/migrate_resources.py` 迁移导入。
管理接口：`/api/admin/resources`（CRUD + 批量导入）。
前端管理页面：`AdminResourceManage.tsx`（管理员后台「学习资源」入口）。
