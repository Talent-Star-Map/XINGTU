## 入口与端口

| 入口 | 当前用途与限制 |
| --- | --- |
| 公网 TCP 443 | HTTPS 网页入口，Nginx 反向代理至本机前端；供评委直接访问 |
| 公网 TCP 80 | ACME HTTP-01 证书验证；其他路径以 308 跳转到同一 IP 的 HTTPS |
| 本机 TCP 3000、8081 | 前端和 API，仅绑定 `127.0.0.1`；未作为公网端口放行 |
| 本机 TCP 3308、27017、7474、7687 | MySQL、MongoDB、Neo4j HTTP/Bolt，仅绑定 `127.0.0.1`；团队通过 SSH 隧道访问 |
| 既有 SSH 22、远程桌面 3389、ICMP 规则 | 本轮未修改；保留既有云侧规则不表示对应服务正在监听 |

`http://127.0.0.1:13000/` 仍是团队本机 SSH 隧道入口，不是能直接转发给评委的公网地址。公网通过网页 API 访问业务，数据库并未因此允许公网直连；API 的身份与资源归属检查仍需持续维护。
