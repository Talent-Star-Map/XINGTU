# 2026-11-18 星图品牌与登录界面

首页和登录页共用持续运行的星图画布。选择角色后，中央星图聚合并编织表单轮廓；表单显现后，编织星链淡去。背景小星图持续运动，返回首页时恢复主星图。登录入口支持悬停提亮和随滚动虚化退场。

品牌采用用户确认的星坐标图形与字标，使用 SVG 轮廓资产，统一首页、页脚、登录页、三角色导航和浏览器图标。深浅主题使用对应反色版本，手机导航使用紧凑尺寸。

登录界面使用较大的输入文字和输入区，返回链接位于框内。首页与登录页保持设计确认时的原始比例，站内页面继续使用已有的 125% 缩放。现有登录、注册、验证码请求与凭据处理保持原样，公开分享、简历阅读及失效登录处理继续保留。

本地验证：生产构建和类型检查通过；三角色品牌、深浅主题、手机到宽屏、键盘、直接访问、返回、减少动态和无 Canvas 回退已检查。登录与注册请求验证使用本地模拟响应。发布范围仅为前端，不包含数据库、后端、环境文件或原工作副本中的其他改动。
