# 星图浏览器陪伴

配套Edge/Chrome ManifestV3扩展和本地小星宿主。打开受支持的星图地址后自动联动；切换标签页、最小化浏览器时桌面小星继续陪伴。关闭该浏览器配置的最后一个普通窗口后结束联动。多个标签页共用一只小星，多个浏览器连接由宿主计数。点击小星面板或托盘的“打开星图”优先唤回已有页面。

网页内小星在没有扩展或本地宿主不可用时继续工作；桌面联动成功后页面内的一份停止播放并隐藏。

支持地址在sites.json明确列出。新增真实部署地址时同时更新匹配清单并重新加载扩展。扩展使用nativeMessaging和明确站点的host_permissions，不申请所有网页、Cookie或屏幕读取权限。

交付包内先运行当前用户安装脚本注册本地宿主，再在Edge/Chrome扩展页加载此文件夹。卸载脚本只移除指向当前交付目录的注册项。独立桌宠归档不被修改。
