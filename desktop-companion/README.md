# 星图小星浏览器联动宿主

固定指令由已验收的连续透明视频驱动，网页与桌面共用 `frontend/src/lib/companionMotion.ts` 和 `companionVideo.ts`。此目录为星图浏览器联动版；独立桌面小星另行归档，配置和运行目录互不覆盖。

配合 `browser-companion` 扩展使用。首次运行安装脚本后，在 Edge/Chrome 中加载交付包内的扩展文件夹。打开星图会启动小星，页面切到后台后仍保留；关闭该浏览器配置的最后一个普通窗口后结束联动。面板或托盘的“打开星图”会唤回已有页面。多个标签页共用一只小星；没有扩展或本地宿主时，网页内小星照常工作。

## 开发运行

使用 Node 24。依赖安装在本目录，配置与位置记录位于忽略提交的 `.local-data/`。

```powershell
npm install
node node_modules/electron/install.js
npm run build
npm start
```

Electron 45 需显式运行官方包内的安装脚本。正式交付由扩展启动本地宿主；单独运行本目录仅供开发，无浏览器连接时会自动退出。遵循本机已有网络配置；不要修改全局代理或关闭证书检查。

构建可搬移交付目录：`node build-package.mjs <Electron官方dist目录> <尚不存在的输出目录>`。包中只包含运行代码、扩展和批准的16段动作，不包含个人偏好、连接口令或生成服务凭据。构建完毕再运行包内注册脚本，使本地宿主路径指向最终位置。

正常入口只加载 `frontend/public/mascot/xiaoxing/motion.json` 中 `id: "xiaoxing"`、`approved: true` 的动作包。动作未验收时显示原始小星画像和素材未就绪提示，不启用伪造动作。

## 素材验证

```powershell
npm start -- --review-pack="动作包的绝对目录"
```

该模式明确显示素材验证标识，仅用于开发。`--review-slow` 让原始透明视频以四分之一速播放，不转换媒体或插补姿势。`--review-framed` 使用有边框的不透明诊断窗口，不能证明透明窗口验收通过。

正常入口可附加 `--diagnostics`，输出可访问的只读片段、暂停状态、视频时钟与实际播放速度，供现场验收；它仍加载正常动作包，仍执行素材批准校验，不启用审查慢放。各片段按素材包的速度播放。普通启动不显示此诊断。

## 操作

点击小星打开指令面板，拖动移动位置；聚焦小星后可用方向键移动、Enter/空格展开面板，Escape 关闭。暂停和拖拽均停止视频时钟及步行位移。面板支持大小、暂停、散步偏好、回到角落、收起和退出。收起后可点击托盘、使用托盘菜单“回到角落”，或再次启动程序恢复；恢复时关闭鼠标穿透并聚焦窗口，可继续用键盘打开面板。托盘菜单也能退出。位置、大小和偏好本地保存。

自动散步只从空闲状态开始。基础待机可以立即响应；正在进行的眨眼和身体动作完成后再切换，睡眠状态先完成起身再进入站立动作。安静待机固定身体与手臂，常态只自然眨眼；张望等较大插曲随机低频触发，之间保留安静间隔，暂停和隐藏时不积累待机循环。素材包必须提供独立左右转身和连续步态；不镜像不对称饰物。宿主不采集屏幕内容、键盘全局输入或账号信息。

素材姿态可使用 `standing`、`left-facing`、`right-facing`、`seated`、`seated-eating`、`sleeping`。每个会到达的非站立姿态都须在 `bridges` 中提供回到站立的完整路径；中途收到新指令时，先完成当前片段，再沿真实过渡返回。完整动作序列仍从正面站立出发。

`travel` 支持匀速区间 `{ direction, start, end, frameHeights }` 或 `{ keyframes: [{ time, x }, ...] }`。距离按整个媒体画面的显示高度归一化：512px原片中102px的位移是 `102/512`，不按头顶到鞋底的可见人物高度计算。曲线从时间0、位置0开始，时间严格递增，位置单向或静止，最后一点不能超出视频时长。应根据最终成片的实际落脚校准；动作引导骨架的轨迹不自动等于成片轨迹。

## 验证边界

网页的全局小星和 `/companion` 主展示复用同一状态机与视频播放器。五张形象卡保留静态原画。没有完整验收的 `xiaoxing` 动作包时，网页保留原画、提示素材尚未就绪并停用动作指令；不会用整图摆动、两张吃饭图片交替或定时横移替代连续动作。网页坐标按页面实际 CSS 缩放换算，面板在可用空间内避开人物，窄屏空间不足时优先保持面板可操作。

状态机行为测试：`node ../frontend/tests/companion-motion.test.mjs`。

构建和行为测试通过不代表动作质量、原生透明显示、拖拽、托盘恢复或原画保真已通过。应分别记录正常入口实测、深浅背景、原速与慢速循环、源帧细节及相邻片段端点。参考大肥鱼动作仅作驱动验证，不能随小星正式包发布。
